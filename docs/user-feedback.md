# Tests utilisateurs — QuickOrder V3.1

## Statut : hors périmètre de cette itération

Le brief demande une campagne de tests utilisateurs (3 scénarios minimum, 2 personnes minimum, profils + retours documentés). Cette partie n'a pas été réalisée dans le temps imparti à cette itération de l'audit — le choix a été fait de prioriser la profondeur de l'analyse technique (stratégie, cas de test, bug reports, plan d'amélioration) plutôt que de livrer un volet utilisateurs superficiel.

## Ce qui serait nécessaire pour la compléter

- **Profils testeurs** : 2 personnes minimum, idéalement non familières du code (regard "client").
- **Scénarios proposés** (à adapter) :
  1. Commander un repas de bout en bout (recherche → panier → paiement) sans aide.
  2. Appliquer un coupon de réduction et comprendre le montant final affiché.
  3. Annuler une commande et consulter son historique.
- **Livrable attendu par testeur** : difficultés rencontrées, incompréhensions, suggestions, ressenti général (échelle de satisfaction).

Cette section pourra être complétée ultérieurement en suivant ce canevas.
